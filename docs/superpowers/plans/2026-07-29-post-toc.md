# Post 大纲视觉优化实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将文章页大纲从彩色树状连接线改为无轴胶囊样式，同时用柔和紫、蓝、青保持 H1、H2、H3 的层级辨识度。

**Architecture:** 保留现有大纲模板、目录数据、折叠与滚动逻辑，仅修改 `Post.vue` 的局部大纲 CSS 和 `style.css` 的暗色模式覆盖。桌面侧栏与移动端弹层继续共用现有类名，因此一套样式同时覆盖两种布局。

**Tech Stack:** Vue 3 SFC、CSS、Vite、TypeScript

---

- 修改 `src/views/Post.vue:998-1186`：删除树状连接线，统一链接盒模型，增加三层缩进、柔和配色、Hover、active 胶囊和键盘焦点。
