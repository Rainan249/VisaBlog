# Post 大纲视觉优化设计

## 目标

改善文章页大纲中过多横竖连接线造成的杂乱感，在保留标题层级辨识度的同时，让大纲更适合长文阅读。

## 设计方向

采用“无轴胶囊 + 柔和层级配色”方案：删除所有树状分割线，通过缩进、字号、字重和颜色表达 H1、H2、H3 层级；当前章节使用对应层级颜色的浅色胶囊强调。

## 视觉规则

### 层级

- H1：不额外缩进，字重 600，使用柔和紫色。
- H2：缩进约 18px，字重 500，使用品牌蓝色。
- H3：缩进约 36px，字号更小，使用柔和青色。
- 非活动标题保持对应层级颜色，但降低饱和度，避免影响正文阅读。

### 分割线

删除以下装饰：

- H1、H2 分组左侧竖线。
- 竖线与标题之间的横向连接线。
- H3 标题前的青色短线。

不新增替代轴线或时间线。

### 当前章节

- 标题文字使用该层级较高对比度的颜色。
- 背景使用该层级颜色的低透明度版本。
- 标题左侧显示约 5px 的同色圆点。
- 胶囊圆角约 6px，不使用完全圆润的药丸形状。
- 活动状态不得改变布局尺寸，避免滚动时跳动。

### Hover

- 使用比活动状态更淡的同层级背景色。
- 不改变字重，避免文字宽度变化。
- Hover 与 active 同时存在时，以 active 样式为准。

## 保留功能

- 单组展开和收起。
- 全部展开和全部收起。
- 阅读进度条和章节计数。
- 当前章节自动跟随与目录自动滚动。
- 桌面侧栏与移动端目录弹层使用同一套层级样式。

## 明暗主题

- 浅色模式使用低透明度紫、蓝、青背景。
- 暗色模式提高标题文字亮度，活动背景保持低透明度，避免刺眼色块。
- 中性标题、计数器和控件颜色优先使用现有主题变量。

## 实施范围

主要修改 `src/views/Post.vue` 的大纲 CSS，不改变目录数据结构、标题解析、滚动监听或折叠逻辑。桌面端和移动端共用现有类名，避免新增重复模板。

## 验收标准

- 大纲中不再出现树状横线或竖线。
- H1、H2、H3 分别呈柔和紫、蓝、青色，并能通过缩进和字号识别层级。
- 当前标题显示对应颜色的浅色胶囊与圆点。
- 长标题换行后背景、圆点和缩进保持正确。
- 展开、收起、滚动定位和自动高亮行为不变。
- 桌面与移动端、浅色与暗色主题均显示正常。
- 键盘焦点状态清晰可见。
