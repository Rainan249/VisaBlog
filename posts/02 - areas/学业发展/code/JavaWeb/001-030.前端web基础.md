# 二.JavaScript
## (一)组成
### 1.ECMAScript
规定了JS基础语法的核心知识 包括变量 数据类型 流程控制 函数 对象等
### 2.BOM
浏览器对象模型 用于操作浏览器本身 如：页面弹窗 地址栏操作 关闭窗口等
### 3.DOM
文档对象模型 用于操作HTML文档 如：改变标签内的内容  改变标签页内字体样式等
## (二)JS引入方式
### 1.内部脚本
- JS代码写在script标签之间
- 在HTML文档中 可以放置任意数量的sript
- 一般置于body的底部 可改善显示速度
### 2.外部引入
将JS代码定义在外部JS文件中 然后引入到HTML页面中
```html
	<sript src=index.js"">
		//你好 我是一段JS代码
	</script>
```
## (三)基础语法
### 1.let(变量)
常用let关键字来声明变量(弱类型语言，变量可以存放不同类型的值)
### 2.const(常量)
用const关键字声明常量
### 3.遵循规则
- 只能用 字母、数字、下划线、美元符号组成 且数字不能开头
- 变量名严格区分大小写
- 不能用关键字

### 6.函数
由于JS是弱语言类型 形参和返回值都不需要制定类型
#### (1)基础函数
在调用函数时 实参个数和形参个数可以不一致
```js
function sum(a, b) {
            return a + b;
        }
        let a = (sum(10, 20));
console.log(a);
```
#### (2)匿名函数
指的是没有名称的函数 可以通过两种方式定义：**函数表达式**和**箭头函数**
```js
 let add = function(a,b){
            return a + b;
        }
        console.log(add(10,20));
```
```js
 let add2 = (a,b) => {
            return a + b;
        }
        console.log(add2(10,20));
```

## (四)DOM
### 1.概念
Document Object Model  文档对象模型
将标记语言的各个组成部分封装为对应的对象
- Document:整个文档对象
- Element:元素对象
- Attribute:属性对象
- Text:文本对象
- Comment:注释对象
![[Pasted image 20260330211009.png]]
### 2.作用
- 改变HTML元素的内容
- 改变HTML元素的样式
- 对HTML DOM事件做出反应
- 添加和删除HTML元素
### 3.内涵
- 将网页中所有的元素当做对象来处理
- 操作步骤
	- 获取要操作的DOM元素当对象
	- 操作DOM对象的属性或方法
- 获取DOM对象
	- 根据CSS选择器来获取DOM元素 获得匹配的第一个元素：document.querySelector('选择器')
	- 根据CSS选择器来获取DOM元素 获得匹配的所有的元素：document.querySelectorAll('选择器')
	- tips:得到的是NodeList节点集合，是一个伪数组(有长度、有索引的数组)
	- 其他获取方法
		- document.getElementById('id')
		- document.getElementByTagName('div')
		- document.getElementByClassName('cls')
## (五)事件监听
### 1.概念
- 事件：HTML事件是发生在HTML元素上的"事情" 比如
	- 按钮被点击
	- 鼠标移动到元素上
	- 按下键盘按钮
- 事件监听：JavaScript可以在事件触发时 就立即调用一个函数做出响应 也称为**事件绑定**或者**注册事件**
- 语法：事件源.addEventListener(’事件类型‘，事件触发执行的函数)
	- 早期语法：事件源.on事件 = function( ){.......}    （绑定多个语法会覆盖 只执行最后一个）
- 事件监听的三要素
	- 事件源：那个DOM触发了事件 要获取DOM元素
	- 事件类型：用什么方式触发 比如：鼠标单击 click
	- 事件触发执行的函数：要做什么事
### 2.常见事件
#### (1)鼠标事件
- click：鼠标点击
- mouseenter：鼠标移入
- mouseleave：鼠标移出
#### (2)键盘事件
- keydown：键盘按下触发
- keyup：键盘弹起触发
#### (3)焦点事件
- focus：获得焦点触发
- blur：失去焦点触发
#### (4)表单事件
input：用户输入时触发
submit：用户提交时触发
### 3.模块化JS
- 源文件 声明script的type为module
	- 语法：<scrip scr = "地址" type = "module"></scrip>
- 导入到HTML的JS 需要导入另一个JS文件
	- 语法：import{ 函数名 } from '另一个JS文件的地址'
- 另一个JS文件需要将函数设置为export

## (三)常用指令
- 指令：HTML标签上带有 v- 前缀的特殊属性 不同的指令具有不同的含义 可以实现不同的功能
```html
 <p v-xxx=".....">.....</p>
```

| 指令                        | 作用                            |
| ------------------------- | ----------------------------- |
| v-for                     | 列表渲染 遍历容器的元素或者对象的属性           |
| v-bind                    | 为HTML标签绑定属性值 如设置herf，css等     |
| v-if / v-else-if / v-else | 条件性的渲染某元素，判定为true时渲染，否则不渲染    |
| v-show                    | 根据条件展示某元素，区别在于切换的是display属性的值 |
| v-module                  | 在表单元素上创建双向数据绑定                |
| v-on                      | 为HTML绑定事件                     |
### 1.v-for
- 作用：列表渲染 遍历容器的元素或者对象的属性
- 语法
```html
<tr v-for="(item,index) in items" :key="item.id">{{item}}</tr>  
```
- 参数说明
	- items为遍历的数组
	- item为遍历出来的元素
	- index为索引/下标，从0开始；可以省略，省略index语法： v-for="item in items"
- key
	- 作用：给元素添加的唯一标识 便于vue进行列表项的正确排序复用 提升渲染性能
	- 推荐使用id为key(唯一) 不推荐使用index作为key(会变化 不对应)
### 2.v-bind
- 插值表达式（  {{ }}  ）不能出现在标签的内部
- 作用：动态为HTML标签绑定属性值 如设置href,src,style样式等
- 语法：
	- b-bind：属性名="属性值"
```html
<img v-bind:src="item.image" width="30px">
```
- 简化：
	- 属性名="属性值"
```html
<img :src="item.image" width="30px">
```
### 3.v-if & v-show
- 作用：控制元素的显示与隐藏
- v-if
	- 语法：v-if = "表达式" 表达值为true 显示false 隐藏
	- 原理：基于条件判断 来控制创建或移除元素节点(条件渲染)
	- 场景：要么显示 要么不显示 不频繁切换的场景
- v-show
	- 语法：v-show=”表达式“ 表达值为true 显示false 隐藏
	- 原理：基于CSS样式disp来控制显示与隐藏
	- 场景：频繁切换显示隐藏的场景
### 4.v-model
- 作用：在表单元素上使用，双向数据绑定。可以方便的 获取 或 设置 表单项数据
- 语法：v-model = "变量名"
### 5.v-on
- 作用：为HTML标签绑定事件(添加时间监听)
- 语法：
	- v-on:事件名="方法名"
	- 简写为  @事件名=“.....”
## (四)vue的生命周期
- 生命周期： 指一个对象从创建到销毁的整个过程
- 生命周期的八个阶段：每一个触发生命周期事件 会自动执行一个生命周期方法(钩子)
![[Pasted image 20260401151905.png]]


| 状态            | 阶段周期  |
| ------------- | ----- |
| beforeCreate  | 创建前   |
| created       | 创建后   |
| beforeMount   | 载入前   |
| mounted       | 挂载完成  |
| beforeUpdate  | 数据更新前 |
| updated       | 数据更新后 |
| beforeUnmount | 组件销毁前 |
| unmounted     | 组件销毁后 |

## Axios
- 介绍：Axios对原生的Ajax进行了封装，简化书写，快速开发
- [官网](https://www.axios-http.cn/)
- 步骤
	- 引入Axios的js文件
	- 使用Axios发送请求，并获取响应结果
![[Pasted image 20260331214812.png]]
- 其他方式
```js
axios.请求方式(url [, data [, config]])
```
### 1.异步请求方式
``` js
document.querySelector('#btnGet').addEventListener('click',()=>{
        axios.get('https://mock.apifox.cn/m1/3083103-0-default/emps/list').then((result)=>{
            console.log(result.data)
        })
        console.log('first coming')  //先输出这一句 因为是异步请求 不会等待结果
    })
```

### 2.async & await
- 可以通过async、await可以让异步变为同步操作  async就是来声明一个异步方法 await是用来等待异步任务执行
```js
methods: {
  async search(){
     //根据用户输入的搜索条件，基于axios发送异步请求(https://web-server.itheima.net/emps/list)到服务端...
     let result = await axios.get('https://web-server.itheima.net/emps/list?name=xxx&gender=xxx&job=xxx');
     this.employees = result.data.data;
  }
}

```
