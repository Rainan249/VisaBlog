# 一.什么是html？
超文本标记语言  HyperTextMarkupLanguage   是一种告知浏览器如何组织页面的标记语言
- 标记也称为标签（元素）
- 大小写都可以 通常都是小写
- HTML由一系列的标签组成
简单来说  学习HTML就是**学习标签

## 1.标签
###    (1)组成
- 符号：标签用 <> 来表示
- 组成：开始标签、结束标签、内容
- 别称：标签也称为**元素**
```html
<h1>标题内容</h1>  //一级标题
<h2>标题内容</h2>  //二级标题
<h3>标题内容</h3>  //三级标题
```
###    (2)分类
- 大部分都是双标签  
- 少数单标签 
```html
<hr>  //一条横线
```

## 2.基本框架
```html
<!DOCTYPE html>  
	//HTML5的声明  告诉浏览器页面的编写规范
	
<html lang="en">  
	//首位两个 <html> 标签 包裹了页面中所有的内容  有时被称为“根元素”
	//lang(即language)声明页面的主要语言  帮助浏览器等正确处理页面内容
	//en代表英语  zh-CN代表中文
	
<head>
	//<head>元素 即头部元素 主要保存供机器处理的信息 而非人类可读信息
	
    <meta charset="UTF-8">
	    //字符集 有这个 页面可以处理任何包含他的语言 不加会乱码
    
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
	    //移动端页面适配
	    
    <title>Document</title>
	    //整个页面的大标题
</head>
	

<body>
	//body元素 包含了在页面上显示的所有内容 包含文本、图片、游戏、视频、可播放音频轨道等等
</body>

</html>
```

## 5.图片元素  #易忘
###    (1)标签

|   属性   | 作用                  |
| :----: | ------------------- |
|  src   | 指向要插入到页面的图像地址       |
|  alt   | 备选本文  图片无法正常显示提示的文字 |
| width  | 设置图片宽度(css)         |
| height | 设置图片高度(css)         |
| title  | 图像标题 鼠标悬停显示的文本      |

```html
<img scr="xxx.img"  alt="图片名称"  width="300"  heigth="300" title="标题">
	//alt名称在图片不存在时候显示
	//长度宽度一般只设置一个 另一会等比例缩放
```

###    (2)类型

| 名称       | 作用                               | 场景                            |
| -------- | -------------------------------- | ----------------------------- |
| jpeg/jpg | 有损压缩技术 放大或缩小会变得模糊或者有锯齿           | 摄影照片、网页图片(非透明背景)              |
| png      | 无损压缩  支持透明度                      | logo、网页图形、需要透明度的图像            |
| gif      | 支持动画、最多265色 支持简单动画和透明背景          | 简单动画、表情包、低色彩图形                |
| WebP     | Google开发的现代格式、支持有损/无损压缩、透明度和动画   | 网页优化(替代jpeg/png/gif)<br>代表淘宝等 |
| avif     | 基于av1的视频编码 支持高压缩率和hdr 压缩效率优于WebP | 未来网页优化，需要高性能优化的场景             |

| 类型    | 示例                           |
| ----- | ---------------------------- |

相对于当前文件位置的路径

## 6.音视频元素  #易忘
###    (1)视频
#### 基本写法
```html
<video src="video/su7.mp4" controls width="400"></video>
```

| 属性       | 作用                |
| -------- | ----------------- |
| autoplay | 自动播放(需要和静音标签一起使用) |
| loop     | 循环播放              |
| muted    | 静音                |
| poster   | 预览图像              |
#### 视频兼容性标签写法
```html
<video controls  width="400">

  <source src="视频地址1.mp4" type="video/mp4">
  <source src="视频地址2.ogg" type="video/ogg">
  <source src="视频地址3.webm" type="video/webm">
  <p>浏览器不支持HTML5 Video标签</p>
  
</video>

	//1.将src属性放在结果单独的<source>文件中 这些元素分别指向各自的资源
	//2.浏览器会检查<source>元素 并且会播放第一个与其自生相匹配的媒体
	//3.每个<source>资源都有type属性 浏览器也会检查这些属性来跳过那些不支持的格式 
	//4.没有这些属性 浏览器会一依次加载每一个文件直到能找到正确的格式 效率不高
```
###    (2)音频
#### 基本写法
```html
<audio src="audio.mp3" autoplay "></audio>
```

| 属性       | 作用                |
| -------- | ----------------- |
| autoplay | 自动播放(需要和静音标签一起使用) |
| loop     | 循环播放              |
| muted    | 静音                |

#### 视频兼容性标签写法
```html
<audio controls="controls" preload="metadata" style="width: 100%;">

  <source src="音频地址1.mp3" type="audio/mp3">
  <source src="音频地址2.ogg" type="audio/ogg">
  <source src="音频地址3.wav" type="audio/wav">
  <p>你的浏览器不支持HTML5 Audio音频播放标签，请更换现代浏览器（如Chrome/Edge/Firefox）后重试</p>
  
</audio>
```

### (3)合并单元格
- 确定跨行（rowspan）还是跨列（colspan）  且值大于1
- 找到目标单元格（左上原则） 写合并数量
- 删除多余行
```html

      <th>
        <tr>
          <th>姓名</th>
          <th>年龄</th>
          <th>性别</th>
        </tr>
      </th>
    </thead>
    <tbody>
      <tr>
        <td>张三</td>
        <td rowspan="3">18</td>
        <td>男</td>
      </tr>
      <tr>
        <td>李四</td>
        <td>女</td>
      </tr>
    </tbody>
  </table>
```

## 10.表单  #易忘
### (1)作用：
手机用户输入数据并将数据提交到后端进行处理
### (2)组成
#### ①表单容器
**form** ：定义表单的容器 包谷所有表单控件
默认包含 action 属性
```html
  <form action = "URL(数据提交的地址)"></form>
```
#### ②表单控件
包含：
##### input 通用输入控件 

| type属性   | 说明      |
| :------- | :------ |
| text     | 单行文本输入框 |
| number   | 数字框     |
| password | 密码框     |
| radio    | 单选框     |
| checkbox | 复选框     |
| file     | 文件域     |

| 其他属性                | 说明                                      |
| ------------------- | --------------------------------------- |
| maxlength           | 允许的最大字符数                                |
| name                | 元素的名称,实现表单的分组                           |
| placeholder         | 提示信息                                    |
| multiple            | 允许多个文件                                  |
| accept              | 规定选择的文件类型，多个类型中间用逗号分割                   |
| checked             | 是否默认选中                                  |
| accesskey           | 使元素获得焦点的快捷键                             |
| autocomplete(默认是on) | 用于控制表单的自动填充行为，是否根据用户的历史输入自动填充字段取值on/off |

##### **textarea** 多行文本输入框

| 常见属性        | 说明            |
| ----------- | ------------- |
| name        | 表单名称          |
| placeholder | 提示信息          |
| rows        | 文本行数，正整数，默认为2 |
| cols        | 文本列数，正整数，默认20 |

#####  select(了解) 下拉选择框

| 常见属性     | 说明                  |
| -------- | ------------------- |
| selected | 默认选中的标签             |
| option   | 每一个选项标签，选项很后面需要加一个值 |
```html
	<li>
        <select name="city" id="">
```

##### **button** 自定义按钮
disabled可以禁用

## 11.字符实体 

| 字符实体       | 数字实体      | 显示效果 | 通俗说明 & 博客使用场景                                      |
| ---------- | --------- | ---- | -------------------------------------------------- |
| `&nbsp;`   | `&#160;`  | （空格） | 强制保留空格（浏览器会合并普通空格），博客里想让文字/符号间有固定空格时用              |
| `&lt;`     | `&#60;`   | <    | 显示小于号，避免被浏览器解析成HTML标签（比如博客里写<p>时，用&lt;p&gt;才能正常显示） |
| `&gt;`     | `&#62;`   | >    | 显示大于号，同上（比如博客里写10&gt;5，避免解析错误）                     |
| `&amp;`    | `&#38;`   | &    | 显示和号（&），所有实体的开头都是&，直接写&会被浏览器识别为实体开头，必须用&amp;       |
| `&quot;`   | `&#34;`   | "    | 显示双引号，博客里引用句子、标注标题时用（比如&quot;阅读笔记&quot;）           |
| `&apos;`   | `&#39;`   | '    | 显示单引号，兼容部分低版本浏览器，博客里写英文引用时用                        |
| `&copy;`   | `&#169;`  | ©    | 版权符号，博客底部加版权信息（比如© 2026 我的阅读笔记）                    |
| `&reg;`    | `&#174;`  | ®    | 注册商标符号，博客里标注原创/专属内容时用                              |
| `&mdash;`  | `&#8212;` | —    | 长破折号（比普通-美观），博客里写随笔、引用时用（比如我偏爱慢阅读——读得深，记得久）        |
| `&hellip;` | `&#8230;` | …    | 省略号，博客里截断文字、表示未完时用（比如这本散文的文字温柔又治愈……）               |
| `&yen;`    | `&#165;`  | ¥    | 人民币符号，博客里写书籍价格时用（比如¥58）                            |
