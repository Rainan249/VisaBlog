# 一.模式转换
## (一).css正常布局流
是指不对页面进行任何布局控制时，浏览器默认的html的布局方式，也称为标准流。正常布局是css布局的基石，页面大的布局基本就是利用区块元素上下罗列而成。

| 区块元素  block                          | 行内元素  inline                                                     |
| ------------------------------------ | ---------------------------------------------------------------- |
| 独占一行<br>垂直方向排列，可设置宽高<br>示例：div p h1等 | 水平方向依次排列，直到容器宽度不足则换行<br>宽度和高度由内容决定，无法直接设置<br>示例：span img strong等 |
## (二).display转换
display属性允许我们更改默认的显示方式

| 语法                   | 作用           | 是否独占一行 | 能否设置宽高 | 默认宽度       |
| -------------------- | ------------ | ------ | ------ | ---------- |
| display：block        | 转为区块元素(最常用)  | 是      | 可以     | 撑满父容器的宽度   |
| display：inline       | 转为行内元素(罕见)   | 否      | 不能     | 由内容决定      |
| display：inline-block | 转为行内区块元素(较少) | 否      | 可以     | 由内容决定(可覆盖) |
## (三)浮动
float浮动可以让元素脱离文档流 向左或者向右浮动 直到碰到父容器边缘或者其他浮动元素
### 1.基本语法

| 属性值   | 作用      | 示例          |
| ----- | ------- | ----------- |
| left  | 左侧浮动    | float：left  |
| right | 右侧浮动    | float：right |
| none  | 默认值 不浮动 | float：none  |
### 2.清除浮动
#### ①额外标签法
在浮动元素的后面新增一个块级标签，添加属性 **clear：both**
#### ②单伪元素清除浮动
父元素添加伪元素
#### ③双伪元素清除浮动
父元素添加双伪元素
#### ④overflow清除浮动
父元素添加overflow
# 二.flex布局(弹性盒子)
flexbox是css弹性盒子布局模块 可以快速实现元素的对齐 分布和空间分配

## (一).父控子
- 父盒子控制子盒子如何排列布局
- 父盒子成为容器  子盒子称为项目

## (二).语法
### 1.父盒子

| 属性              | 作用                                               | 示例                                           |
| --------------- | ------------------------------------------------ | -------------------------------------------- |
| display         | 定义元素为 Flex 容器                                    | .container { display: flex; }                |
| flex-direction  | 定义主轴方向（项目排列方向）                                   | .container { flex-direction: row; }          |
| flex-wrap       | 控制是否换行                                           | .container { flex-wrap: wrap; }              |
| justify-content | 定义主轴上的对齐方式（整体分布）                                 | .container { justify-content: center; }      |
| align-items     | 定义交叉轴上的对齐方式（单行时整体对齐）                             | .container { align-items: center; }          |
| align-content   | 定义多行时交叉轴上的对齐方式 <br>（仅当 flex-wrap: wrap 且内容换行时生效） | .container { align-content: space-between; } |

### 2.子盒子

| 属性         | 作用                                                         | 示例                          |
|--------------|--------------------------------------------------------------|-------------------------------|
| order        | 定义项目的排列顺序（默认 0，数值越小越靠前）                 | .item { order: -1; }          |
| flex-grow    | 定义项目的放大比例（默认 0，即不放大）                       | .item { flex-grow: 1; }       |
| flex-shrink  | 定义项目的缩小比例（默认 1，空间不足时等比缩小）             | .item { flex-shrink: 0; }     |
| flex-basis   | 定义项目在主轴方向上的初始大小（优先级高于 width/height）    | .item { flex-basis: 200px; }  |
| flex         | flex-grow、flex-shrink、flex-basis 的简写                   | .item { flex: 1; }            |
| align-self   | 覆盖容器的 align-items，单独定义某个项目的交叉轴对齐方式      | .item { align-self: center; } |
注意
- 如果子元素有大小 则按照给定大小来显示
- 如果子元素没有大小 则拉伸充满父容器
- 若子元素总宽度超过容器宽度 默认会压缩子元素


## (三).主轴和交叉轴(侧轴)
- 主轴默认水平方向 交叉轴默认垂直方向 可以更改
### 1.定义主轴的对齐方式
justify-content定义主轴的对齐方式

| 属性值           | 效果       | 示例                                     |
| :------------ | :------- | :------------------------------------- |
| flex-start    | 左对齐（默认）  | 子元素靠左排列                                |
| flex-end      | 右对齐      | 子元素靠右排列                                |
| center        | 居中对齐     | 子元素居中                                  |
| space-between | 两端对齐     | 首个子元素放置于起点，末尾元素放置于终点，剩余空间平均分配给各子元素之间   |
| space-around  | 项目两侧间隔相等 | 每个子元素周围分配相同的空间，因此项目之间的间隔比项目与边框之间的间隔大一倍 |
| space-evenly  | 项目间隔均匀分布 | 每个子元素之间的间隔相等，包括首尾元素与容器边框之间的间隔也均等       |
### 2.定义交叉轴的对齐方式
align-items定义交叉轴上的对齐方式(单行时整体对齐)

| 属性值        | 作用描述                    |
| ---------- | ----------------------- |
| flex-start | 项目在交叉轴起点对齐（默认值）         |
| flex-end   | 项目在交叉轴终点对齐              |
| center     | 项目在交叉轴居中对齐              |
| stretch    | 项目拉伸填充整个容器高度（需子项目无固定高度） |

| space-evenly | 项目间隔均匀分布 | 每个子元素之间的间隔相等     |

# 三.定位布局

## (一)相对定位  position：relative
核心在于**元素相对于自身正常位置进行偏移**
- 相对于自身的原来位置进行移动
- 不脱离正常流  元素原位置仍然被保留 其他元素按原布局排列
- 可以通过 top、bottom、left、right属性进行偏移
- 优先级：若四个都设置 则只有top和left生效
## (二)绝对定位 position：absolute
核心是**脱离正常流并基于定位基准进行偏移**
- 元素脱离正常流 不占据空间 其他元素按原布局排列
- 相对于最近的已定位祖先元素(position非static)移动位置 若都无定位 则相对于视口来定位
- 可以通过top、bottom、left、right属性进行偏移
- 优先级：若四个都设置 则只有top和left生效
## (三)固定定位 position：fixed
核心是**将元素脱离文档流并始终相对于浏览器视口定位定位的布局技术**
- 元素脱离正常流
- 始终相对于浏览器窗口定位，滚动页面时位置不变
- 可以通过top、bottom、left、right属性进行偏移
- 优先级：若四个都设置 则只有top和left生效
## (四)粘性定位  position：sticky
核心是**结合了相对定位和固定定位**
- 元素在滚动到指定位置如(top:10px)前为相对定位 之后转为固定定位
- 父容器的overflow需为visible 否则粘性定位失效
- 可以通过top、bottom、left、right属性进行偏移
- 须指定top，right，bottom，left四个其中之一 才能使粘性定位生效

## (五) tips：
### 1.定位布局-层叠顺序
z-index属性用于控制元素在三维空间中的层叠顺序(即z轴的方向)
当多个元素在同一个平面(如同一行或者列)重叠时 
z-index决定哪个元素在最上层
- 值类型：整数(正数、负数、零)或auto   数值越大  层级越高
- 默认值：auto(等同于未设置 后出现的元素覆盖前者)
- 生效条件：仅对 定位元素(position值为relative、absolute、fixed或者sticky有效)
### 2.总结

|   定位类型   | 脱离文档流 |   定位基准    | 层叠控制 |     典型场景     |
| :------: | :---: | :-------: | :--: | :----------: |
|  static  |   否   |   默认文档流   |  无   |    普通元素布局    |
| relative |   否   |  自身正常位置   |  支持  |  微调元素、父绝子相   |
| absolute |   是   | 最近定位祖先/视口 |  支持  | 弹窗、下拉菜单、悬浮元素 |
|  fixed   |   是   |    视口     |  支持  | 固定导航栏、返回顶部按钮 |
|  sticky  |   否   |  视口或滚动祖先  |  支持  | 吸顶导航栏、侧边栏固定  |

# 四.grid布局(网格布局)

display：grid(块级)或者display：inline-grid(行内)
## (一).绘制网格
定义网格中的列：grid-template-columns 
定义网格中的行：grid-template-rows
## (二).属性值
- 有几个属性值代表创建几行或者几列
- 长度单位比如 100px
```css
grid-template-columns :200px 200px 200px;
/*定义三列 每列的宽度为200px*/
grid-template-rows:200px 200px 200px;
/*定义三行 每行的宽度为200px*/
```

## (三).对齐方式
justify-content是控制**列轨道** 
align-content是控制**行轨道**

| 属性值           | 水平方向效果          | 垂直方向效果               |
| ------------- | --------------- | -------------------- |
| start(默认)     | 左对齐             | 顶部对齐                 |
| end           | 右对齐             | 底部对齐                 |
| center        | 水平居中对齐          | 垂直居中对齐               |
| space-around  | 两侧留出空白 项目周围均匀分布 | 上下留出相等的空白 项目周围空间均匀分布 |
| space-between | 首尾项目贴边          | 上下项目贴边               |
| space-evenly  | 项目间 、首尾与边界的空白相等 | 项目间、首尾与边界的空白相等       |
## (四).绘制方式
| 属性值         | 说明                                                   | 示例                                                          | 应用场景          |
| ----------- | ---------------------------------------------------- | ----------------------------------------------------------- | ------------- |
| 固定长度        | 使用 px、em 等固定单位定义列宽                                   | `grid-template-columns: 100px 200px;`                       | 需要精确控制列宽的固定布局 |
| 百分比         | 按容器宽度百分比分配列宽                                         | `grid-template-columns: 30% 70%;`                           | 响应式布局中按比例划分列  |
| fr 单位       | 分配轨道剩余空间的比例（1fr 表示一份，总和为容器剩余空间）fr 是 fraction 缩写，意思分数 | `grid-template-columns: 1fr 2fr;`                           | 需要自适应比例分配的布局  |
| auto        | 列宽由内容自动撑开                                            | `grid-template-columns: auto 100px;`                        | 内容宽度不确定时的灵活布局 |
| repeat() 函数 | 简化重复的列定义                                             | `grid-template-columns: repeat(3, 1fr);`（等效于 `1fr 1fr 1fr`） | 多列等宽布局        |
| minmax() 函数 | 定义列宽的最小值和最大值                                         | `grid-template-columns: minmax(100px, 1fr);`                | 响应式布局中限制列宽范围  |
## (五).gap属性

| 写法                              | 说明                       |
| ------------------------------- | ------------------------ |
| gap：20px                        | 行和列都是20px间距              |
| gap：20px  30px                  | 行是20px间距  列是30px间距       |
| column-gap：30px<br>row-gap：20px | 可以分开写<br>行是30px   列是20px |
## (六).repeat()函数
### 1.语法
repeat(次数，轨道尺寸) 或 repeat(自动填充，轨道尺寸)
### 2.用法
#### ①固定次数
grid-template-columns：repeat(3,1fr)
#### ②自动填充
适用于响应式布局中“列数随容器宽度变化”的场景
auto-fill：尽可能多创建列
auto-fit：尽可能拉伸列填满容器(会合并空白，列宽不小于minmax的最小值)
#### ③minmax()函数
minmax(最小值，最大值)   minmax(200px，1fr)
