# 一.css3基础知识(css)
## (一)css简介
css(cascading style sheets，层叠式样表)，是用来控制网页在浏览器中显示外观的语言
## (二)css分类
### 1.内联样式表(行内样式表)
样式写到标签内部，可以控制当前标签的样式，特殊情况使用
```CSS
<!-- 一个标签里写3个样式属性，控制颜色、字号、行高 -->
<p style="color: #2f54eb; font-size: 16px; line-height: 1.8;">这是内联样式的段落</p>
```
### 2.内部样式表
写到**head**标签中，脱离结构，可以控制当前页面的所有标签，较为常用
### 3.外部样式表
单独新建一个css文件，完全脱离结构，可以控制整个网站的所有标签，最常用
```css
 <link rel="stylesheet" href="style.css">
```

# 二.css3选择器(selector)
## (一)选择器简介
css选择器是css规则的一部分 是选择html元素的方式
```css
strong {
  color: red;
  font-size: 30px;
}
```
其中**strong**是选择器
**color**和**font-size**是属性
>css属性：采用键值对的形式  属性名：属性值
## (二)分类
### 1.基础选择器
#### (1)类型选择器
选择某个类型的元素 也称为标签选择器(具有层叠性 就近原则)
```css
	p {
      color: red;
      font-size: 30px;-
    }
    div {
      color: blue;
    }
    strong {
      color: black;
    }
```
#### (2)类选择器
可以选择一个或多个元素
```css
.pink {
      color: pink;
    }
.sub-nav {
      font-size: 20px;
    }    
    
    ··········
    
   <div class="pink sub-nav">我是div</div>
```
tips：
- 类名自定义 不能是中文、纯数字
- 多个英文单词尽量使用 - 链接
- 命名要有意义，尽量见名知义
- class属性可以有多类名 中间用空格隔开
#### (3)id选择器
```css
#black {
      color: black;
    }
    
    ··········
    
    <strong id="black">我是加粗</strong>
```

二者对比：

| 名称  | 类选择器                 | id选择器                     |
| --- | -------------------- | ------------------------- |
| 语法  | 以 . 开头 后跟类名(如： .nav) | 以 # 开头  后跟id名(如：# header) |
| 作用  | 选择class属性的一个或多个元素    | 选择特定id属性的唯一元素             |
| 特点  | 可以使用多次               | 同一页面中 id值必须唯一             |
| 类似  | 身份证的名字 可以使用多次        | 身份证的编号 唯一 只能使用一次          |
| 场景  | 后期修改样式基本都是类选择器       | 后期主要是配合JavaScript添加交互效果   |

#### (4)通配符选择器
可以选择html中所有的标签  进行样式修改
特殊情况下通过通配符清除所有元素的默认边距和填充 统一不同浏览器的默认演样式
```css
*{
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}
```

#### (5)总结  #易忘 

| 选择器类型   | 语法示例      | 匹配范围                     | 复用性     | 典型使用场景                     | 注意事项                     |
| ------------ | ------------- | ---------------------------- | ---------- | -------------------------------- | ---------------------------- |
| 类型选择器   | `div {...}`   | 匹配所有指定 HTML 标签元素   | 某一类型标签 | 全局样式重置、基础标签样式（如 body, p） | 避免滥用，可能导致样式冲突   |
| 类选择器     | `.nav {...}`  | 匹配所有含指定 class 的元素  | 多次使用   | 多元素共享样式                   | 优先使用，避免与 ID 选择器冲突 |
| ID 选择器    | `#header {...}` | 匹配唯一含指定 id 的元素     | 唯一性     | 唯一元素标识                     | 必须唯一，避免样式覆盖风险   |
| 通配符选择器 | `* {...}`     | 匹配所有元素                 | 全局覆盖   | 全局样式重置                     | 性能较差，慎用               |

### 2.关系选择器
#### (1)后代选择器
选择某个元素的后代元素(不限层级 包括子元素 孙元素等)
```html 
 div p{
	 color: pink;
 }
	··········
<div>
	<p>我是文字</p>
</div>
 
 <p>我是文字</p>
 
```
#### (2)子代选择器
```html
header > h1 {
  color: green;
  font-size: 20px;
}

  ··········
  
<header>
  <!-- 这是header的直接子h1 → 会被选中（变绿） -->
  <h1>页面标题</h1>
  <div>
    <!-- 这是div的子h1（不是header的直接子）→ 不会被选中 -->
    <h1>嵌套标题</h1>
  </div>
</header>
```

#### (3)领接兄弟选择器
```html
h2 + p {
  color: red; /* 只有第一个段落会变红 */
  font-weight: bold;
}

 ··········
 
 <div>
  <h2>这是一个标题</h2>
  <p>这个段落会被选中（变红并加粗）。</p> <!-- 被选中 -->
  <p>这个段落不会被选中。</p>
  <p>这个段落也不会被选中。</p>
</div>
```

#### (4)通用兄弟选择器
```html
h2 ~ p {
  color: blue; /* 所有在 h2 之后的段落都会变蓝 */
  background-color: #f0f0f0;
}
	··········
<div>
  <h2>这是一个标题</h2>
  <p>这个段落会被选中（变蓝）。</p> <!-- 被选中 -->
  <span>这个 span 不会被选中。</span>
  <p>这个段落也会被选中（变蓝）。</p> <!-- 被选中 -->
  <p>这个段落同样会被选中（变蓝）。</p> <!-- 被选中 -->
</div>
```
#### (5)总结 #易忘 

| 选择器     | 语法    | 选择范围       |
| ------- | ----- | ---------- |
| 后代选择器   | A B   | 所有后代（跨层级）  |
| 子代选择器   | A > B | 直接子元素（仅一层） |
| 领接兄弟选择器 | A + B | 紧邻的下一个同级元素 |
| 通用兄弟选择器 | A ~ B | A之后所有的同级元素 |

### 3.优先级  #易忘 
浏览器通过优先级来判断那些属性值与一个元素最为相关，优先级是基于不同种类选择器组成的匹配原则
原则
1.优先级相同的时候，css中最后的那个声明的样式将会被应用到元素上（层叠遵循就近原则）
2.其余判断那个选择器权重高，优先执行那个样式
3.权重是4位一组，是分开的层级，不能进位

| 选择器类型      | 示例                        | 权重值       | 优先级说明              |
| ---------- | ------------------------- | --------- | ------------------ |
| !improtant | color : red ! important   | 无限大       | 强制覆盖所有规则(慎用)       |
| 内联样式       | < div style="color:red" > | (1,0,0,0) | 行内样式权重最高(1,0,0,0)  |
| ID选择器      | 井 myld                    | (0,1,0,0) | 每个ID增加0,1,0,0      |
| 类/属性/伪类    | .class, [type="text]      | (0,0,1,0) | 每个类/属性/伪类增加0,0,1,0 |
| 类型(标签)/伪元素 | div, ::after              | (0,0,0,1) | 每个标签/              |
| 通配符/继承     | *，继承的样式                   | (0,0,0,0) | 通配符和继承权重最低         |

# 三.盒子模型(box)
## (一)分类
### 1.区块盒子(block)
- 盒子会产生换行
- width和height属性可以发挥作用
- 不设置宽度则默认和是父元素空间的100%
- 内边距、外边距和边框会撑大元素
- 常见的比如：div、p、h、ul、table
### 2.行内盒子(inline)
- 盒子不会产生换行
- width和heigh属性将不起作用
- 垂直方向的内边距、外边距不起效果
- 水平方向的内边距、外边距会有效果
- 常见的比如:span、em、a、strong等
## (二)组成
### 1.盒子内容：
#### 描述：
显示内容的区域，由内容或者指定宽度高度来决定内容大小

### 2.内边距padding：
#### 描述：
内容距离边框之间的距离

| 内边距写法                        | 作用                      |
| ---------------------------- | ----------------------- |
| padding：10px；                | 上下左右4个内边距都是10px         |
| padding：10px 20px；           | 上下内边距是10px  左右内边距是20px  |
| padding：10px 20px 30px；      | 上是10px  左右是20px  下是30px |
| padding：10px 20px 30px 40px； | 上10px 右20px 下30px 左40px |

### 3.边框border：
#### ①基础边框
##### 描述：
边框盒子包住内容和内边距
##### 使用场景：
设置盒子四条或者单条边框
##### 属性值：
border：边框粗细 边框样式 边框颜色
- 边框有三部分属性值组成(像素 边框样式 颜色) 中间必须空格隔开
- 三部分属性值没有先后顺序


| 边框样式   | 描述   | 视觉效果     |
| ------ | ---- | -------- |
| dotted | 点状边框 | 圆点组成的虚线  |
| dashed | 虚线边框 | 短横线组成的虚线 |
| solid  | 实线边框 | 单一条线     |

#### ②圆角边框
**border-radius**
用于盒子模型或者修改图

| 圆角写法                                | 作用                             |
| ----------------------------------- | ------------------------------ |
| border-radius: 10px;                | 上下左右都是10px                     |
| border-radius: 10px 20px;           | 左上 右下是10px     右上 左下是20px      |
| border-radius: 10px 20px 30px;      | 左上是10px  右上 左下是20px  右下是30px   |
| border-radius: 10px 20px 30px 40px; | 左上10px  右上20px  右下30px  左下40px |
- 顺时针记忆
- 中间空格隔开
- 不需要的设置成0即可
#### ③图片边框
- CSS 图片边框属性专用表

| 属性 | 可选值/语法 | 描述 | 示例 |
|------|------------|------|------|
| **border-image-source** | `url('path/to/image.png')`<br>`linear-gradient(...)`<br>`radial-gradient(...)`<br>`none` | 指定用作边框的图片或渐变 | `border-image-source: url('border.png');`<br>`border-image-source: linear-gradient(red, blue);` |
| **border-image-slice** | `number` (无单位，1-4个值)<br>`number%` (百分比，1-4个值)<br>`fill` | 将图片切割为9个区域，指定切割位置 | `border-image-slice: 30;`<br>`border-image-slice: 25% 30;`<br>`border-image-slice: 10% 20% 30% fill;` |
| **border-image-width** | `length`<br>`percentage`<br>`number` (倍数)<br>`auto` | 边框图片的显示宽度 | `border-image-width: 20px;`<br>`border-image-width: 2;` (2倍切片值)<br>`border-image-width: 10% 15px;` |
| **border-image-outset** | `length`<br>`number` (倍数) | 边框图片向外延伸的距离 | `border-image-outset: 5px;`<br>`border-image-outset: 1.5;` (1.5倍边框宽度) |
| **border-image-repeat** | `stretch`<br>`repeat`<br>`round`<br>`space`<br>`stretch round` (两个值) | 边框图片的平铺/重复方式 | `border-image-repeat: round;`<br>`border-image-repeat: stretch round;` (水平/垂直) |
| **border-image** (简写) | `source slice / width / outset repeat` | 所有图片边框属性的简写 | `border-image: url(border.png) 30 / 20px / 5px round;`<br>`border-image: linear-gradient(red, blue) 30 stretch;` |
- **border-image-slice 切片说明**：
- 1个值：四个方向相同
- 2个值：上下 / 左右
- 3个值：上 / 左右 / 下
- 4个值：上 / 右 / 下 / 左（顺时针）

- **border-image-repeat 选项**：
- `stretch`：拉伸填充（默认）
- `repeat`：平铺，可能被截断
- `round`：平铺，调整图片大小以完整填充
- `space`：平铺，均匀分布空白空间

### 4.外边距margin：
该盒子与其他元素之间的距离

| 外边距写法                       | 作用                         |
| --------------------------- | -------------------------- |
| margin：10px；                | 上下左右4个外边距都是10px            |
| margin：10px 20px；           | 上下外边距是10px 左右外边距是20px      |
| margin：10px 20px 30px；      | 上是10px  左右是20px  下是30px    |
| margin：10px 20px 30px 40px； | 上10px  右20px  下30px  左40px |

注意
- 行内元素左右外边距生效  上下外边距无效  
- 行内元素设置宽度和高度也无效

技巧：
区块元素可以利用margin实现水平居中
- 块级盒子必须要有宽度
- 只需要设置左右外边距为auto就可以

缺点：
①区块元素上下外边距会出现折叠(合并)情况
- 并列关系(兄弟)的区块元素
- 两个上下外边距将合并为一个外边距 其大小等于最大的单个外边距
解决办法：浏览器特性 只设置一个盒子外边距即可


②区块元素上下边距会出现塌陷情况
- 嵌套关系(父子)的区块元素
- 给子盒子设置上下外边距会让父盒子塌陷移动
解决办法：给父盒子添加**上边框**、**上内边框**、**overflow：hidden属性**

### 2.盒子背景  #易忘 
background用于设置背景相关属性，包括背景颜色、背景图片、背景位置、背景重复方式等

使用场景
- 给盒子添加背景图片 更加精美
- 给列表添加相同的小图标 装饰效果
- 给页面添加大的背景图片展示更震撼
- 纯css实现背景渐变效果

| 属性                    | 作用         | 常用值                                    |
| --------------------- | ---------- | -------------------------------------- |
| background-color      | 设置元素背景颜色   | 颜色名称、十六进制、RGB、透明度                      |
| background-image      | 设置背景图片     | url(image.jpg)                         |
| background-repeat     | 控制背景图片是否重复 | repeat（默认）、no-repeat、repeat-x、repeat-y |
| background-position   | 定位背景图片位置   | x y（如 center top，或者 px、% 单位）           |
| background-size       | 调整背景图片尺寸   | 默认auto、over（覆盖）、contain（包含）或者跟 px、%    |
| background-attachment | 背景是否随页面滚动  | scroll（默认）、fixed                       |

#### 复合写法：
background：颜色 图片 重复 固定 位置/尺寸 (顺序随意)

#### 背景渐变：

| 属性/方法                                               | 描述             |
| --------------------------------------------------- | -------------- |
| background：linear-gradient(方向，颜色1  位置，颜色2  位置.....) | 线性渐变(方向可控)     |
| background：radial-gradient(形状，颜色1，颜色2)              | 径向渐变(形状和位置都可控) |


| 文字背景线性渐变                                         | 作用             |
| ------------------------------------------------ | -------------- |
| background：linear-gradient(to right, pink, red); | 设置背景渐变         |
| -webkit- background-clip:text;                   | 兼容性写法 适配老版本浏览器 |
| background-clip: text                            | 文字范围裁剪背景       |
| -webkit-text-fill-color:transparent              | 文本填充颜设置为透明     |

### 3.盒子阴影
box-shadow属性用于在元素的框架上添加阴影效果
#### ①使用场景
- 盒子添加阴影 效果更立体
- 鼠标经过元素显示阴影  更加突出元素
#### ②语法
- 多个属性用空格隔开
- x轴偏移量和y轴偏移量是必须要写 其余可以省略采取默认值
- 默认是外阴影 如果改为内阴影要写inset
```css
.nav li{
	box-shadow:0 15px 30px white;
	/! x偏移量 y偏移量  模糊半径  扩散半径 颜色   !/
}
```

#### ③过渡效果
场景
- 鼠标经过图片放大
- 表单获得焦点 输入框变宽
语法：
**transition：过渡属性 过渡时间**
- 属性值中间空格隔开
- 过渡属性如果都要变化可以写all
- 过渡时间单位是s

#### ④样式初始化
中大型项目：推荐 “Normalize.css”
#### ⑤单行文字溢出显示省略号

| 方法                     | 作用        |
| ---------------------- | --------- |
| text-overflow:ellipsis | 文字溢出显示省略号 |
| white-space：nowrap     | 文字不换行     |
| overflow：hidden        | 元素溢出时隐藏   |

# 四.精灵图(sprites)
将多个小图标或者图像合并到一张大图中，通过调整background-position属性来显示特定部分的图像技术
## (一)优势
1.减少http请求：多个小图标合并为一张图片，只需一次请求
2.提升性能：减少网络开销，尤其适合移动端或者低宽带场景
3.统一管理：方便维护图表集，避免文件分散
## (二)原理
1.给盒子添加背景图片
2.通过背景定位(background-position)移动位置对齐
3.注意网页的坐标不同
# 五.字体图标(iconfont)
## (一)使用场景
1.导航菜单图标
2.按钮操作图标
3.结合动画效果
## (二)优势
1.矢量缩放:无损放大或者缩小
