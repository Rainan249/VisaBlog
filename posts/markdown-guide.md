Markdown 是一种轻量级标记语言，写博客非常方便。

## 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
```

## 文本样式

- **粗体** `**粗体**`
- *斜体* `*斜体*`
- ~~删除线~~ `~~删除线~~`

## 代码

行内代码 `console.log()` 用反引号包裹。

代码块用三个反引号：

```python
def hello():
    print("Hello, World!")
```

## 列表

无序列表用 `- ` 开头：

- 苹果
- 香蕉
- 橘子

有序列表用数字：

1. 第一步
2. 第二步
3. 第三步
